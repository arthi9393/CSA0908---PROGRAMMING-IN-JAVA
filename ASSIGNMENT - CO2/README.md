## 1. INTRODUCTION

This repository contains the implementation of Assignment 2 for the Programming in Java course.

The assignment focuses on Java Collections Framework, String handling, performance analysis, generics, comparators, priority queues, and program optimization.

The programs are implemented in Java and tested using Visual Studio Code.

## 2. OBJECTIVES

- Understand the differences between String, StringBuilder and StringBuffer.
- Compare ArrayList, LinkedList and ArrayDeque.
- Understand HashSet and the equals() and hashCode() methods.
- Compare HashMap, TreeMap and LinkedHashMap.
- Implement generic classes and Comparator interfaces.
- Understand PriorityQueue and priority-based scheduling.
- Identify performance bottlenecks and improve program efficiency.

## 3. ASSIGNMENT TASKS

### Q1 – String, StringBuilder and StringBuffer
Compare the performance and characteristics of String, StringBuilder and StringBuffer through repeated string operations.

### Q2 – ArrayList, LinkedList and ArrayDeque
Compare the performance of different Java collection classes using insertion and other collection operations.

### Q3 – HashSet and equals() / hashCode()
Study duplicate handling in HashSet and understand the contract between equals() and hashCode().

### Q4 – HashMap, TreeMap and LinkedHashMap
Compare different Map implementations based on ordering, performance and key-value operations.

### Q5 – Generics and Comparator
Implement a generic Leaderboard class and use Comparator to sort objects based on multiple criteria.

### Q6 – PriorityQueue
Implement a priority-based triage system using PriorityQueue and study fairness and arrival-order handling.

### Q7 – Diagnose, Redesign and Validate
Identify a performance bottleneck, redesign the implementation and validate the improvement using experimental results.
