## Project 2: CSA09 – Programming in Java – Assignment 3 (CO3)

Java programs covering exception handling, resource management, multithreading, synchronization, inter-thread communication, and concurrent processing.

### Assignment Structure

- `Q1_ATM_Exception/` — ATM exception handling
- `Q2_Custom_Exception/` — Custom exceptions
- `Q3_Resource_Management/` — File and resource management
- `Q4_Thread_Lifecycle/` — Thread lifecycle
- `Q5_Seat_Booking/` — Synchronized seat booking
- `Q6_Deadlock_Communication/` — Deadlock prevention and thread communication
- `Q7_Concurrent_Processor/` — Concurrent result processing

### How to Run Assignment 3

Open the terminal in the `ASSIGNMENT-CO3` folder.

```powershell
javac Q1_ATM_Exception/ATM.java
java -cp Q1_ATM_Exception ATM

javac Q2_Custom_Exception/StorageDemo.java Q2_Custom_Exception/PortalDemo.java
java -cp Q2_Custom_Exception StorageDemo
java -cp Q2_Custom_Exception PortalDemo

javac Q3_Resource_Management/ResourceDemo.java
java -cp Q3_Resource_Management ResourceDemo

javac Q4_Thread_Lifecycle/ThreadDemo.java
java -cp Q4_Thread_Lifecycle ThreadDemo

javac Q5_Seat_Booking/SeatBooking.java
java -cp Q5_Seat_Booking SeatBooking

javac Q6_Deadlock_Communication/TokenCounter.java Q6_Deadlock_Communication/WalletTransferDemo.java
java -cp Q6_Deadlock_Communication TokenCounter
java -cp Q6_Deadlock_Communication WalletTransferDemo

javac Q7_Concurrent_Processor/ResultProcessor.java
java -cp Q7_Concurrent_Processor ResultProcessor
```
